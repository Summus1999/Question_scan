# Question Scan MVP 手动验证清单

> 验证环境：Windows 桌面  
> 验证命令：`npm run tauri dev`（开发模式）或安装包运行  
> 前置条件：已配置有效的多模态 AI API Key（如 DeepSeek V4 Pro）

---

## 一、应用启动与基础界面

### 1.1 启动与托盘

| 步骤 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
| 1.1.1 | 运行 `npm run tauri dev` 或双击安装包启动 | 应用启动，任务栏托盘出现 Question Scan 图标 | |
| 1.1.2 | 观察托盘图标 | 图标显示正常，tooltip 显示 "Question Scan" | |
| 1.1.3 | 点击托盘图标右键 | 弹出菜单：打开窗口 / 打开设置 / 启用快捷键 / 禁用快捷键 / 退出 | |
| 1.1.4 | 点击"打开窗口" | 主窗口从托盘状态显示到前台 | |
| 1.1.5 | 点击主窗口关闭按钮（X） | 窗口隐藏到托盘，应用仍在后台运行 | |
| 1.1.6 | 点击托盘"退出" | 应用完全退出，托盘图标消失 | |

### 1.2 主界面布局

| 步骤 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |

| 1.2.2 | 检查控制区 | 包含快捷键显示、状态指示器、触发按钮 | |
| 1.2.3 | 检查设置区 | 包含 AI Provider、API Key、模型、语言、速度等设置项 | |
| 1.2.4 | 检查结果面板 | 显示空闲状态占位文案 | |

### 1.3 界面语言切换

| 步骤 | 操作 | 预期结果 | 实际结果 |
| --- | --- | --- | --- |
